JF Private Health Dashboard Privacy Policy

Effective date: August 4, 2026

JF Private Health Dashboard is a private, personal-use health dashboard operated by Norane Health Lab. It is not offered as a public service.

Information accessed

With the user's authorization, the app may read the following data from WHOOP:

  • Recovery data
  • Physiological cycle data
  • Sleep data
  • Workout data

The app does not request WHOOP profile or body-measurement permissions. OAuth credentials and access tokens are used only to connect the local dashboard to the WHOOP API.

How information is used

Information is used only to create a private personal-health dashboard, calculate personal trends, and show data freshness. It is not used for advertising, profiling, automated eligibility decisions, or medical diagnosis.

Storage and security

WHOOP data and OAuth credentials are stored locally on the authorized user's own computer. Credentials are kept outside the dashboard workspace and source-control repositories. The app uses HTTPS, least-privilege read scopes, private local file permissions, bounded API requests, and rotating OAuth tokens.

Sharing and sale

Personal information is not sold, rented, licensed, or shared with advertisers or data brokers. Data is transmitted only between the user's local computer and WHOOP as needed to provide the dashboard.

Retention and deletion

Information remains on the user's local computer until the user deletes it. The user may stop future access by revoking the app in WHOOP and may delete the local dashboard database and OAuth files at any time.

Third-party service

WHOOP processes information under its own privacy policy. This policy covers the local JF Private Health Dashboard integration.

Children and medical use

The app is not directed to children and is not a medical device. It does not provide medical advice.

Changes

If this policy changes, the effective date above will be updated. Material changes to data access or use will require renewed review before the app is used.

Contact

Questions or deletion requests can be submitted through the repository's GitHub Issues page.
