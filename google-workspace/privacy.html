Atlas Read-Only Workspace Privacy Policy

Effective date: September 4, 2026

Atlas Read-Only Workspace is a private, personal-use integration. It is not offered as a public service.

Google data accessed

With the user's authorization, the integration may read:

  • Gmail messages and threads, including message metadata, participants, subjects, timestamps, labels, and relevant message content
  • Google Calendar events, including titles, times, participants, locations, descriptions, and response status

The integration requests only the gmail.readonly and calendar.readonly OAuth scopes. It cannot send, change, or delete Gmail or Google Calendar data.

How Google data is used

Google data is used only to create private daily briefs, identify relevant commitments and follow-ups, and maintain the minimum state needed to avoid duplicate reporting. It is not used for advertising, credit decisions, surveillance, or building public profiles.

Email and calendar information may be processed by the AI model configured in the user's private Hermes Agent environment solely to generate the requested summaries and reminders.

Storage and security

OAuth credentials, collector state, and generated brief files are stored in the authorized user's private, owner-controlled environment. OAuth token files are restricted to the local account. The collector enforces exact read-only scopes, bounded API requests, and redacted error reporting.

Sharing and sale

Google user data is not sold, rented, licensed, or shared with advertisers or data brokers. Data is transmitted only to Google APIs, the user's private Hermes Agent environment, and the AI model provider configured by that user when needed to generate a requested brief.

Retention and deletion

OAuth credentials, local collector state, and generated briefs remain in the user's private environment until the user deletes them. The user may stop future access at any time by revoking the app in their Google Account and deleting the local OAuth token and generated files.

Google API Services User Data Policy

The integration's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Changes

If this policy changes, the effective date above will be updated. Material changes to data access or use require review before the integration is used again.

Contact

Questions or deletion requests can be submitted through the repository's GitHub Issues page. Do not include email, calendar, health, credential, or other sensitive information in a public issue.
