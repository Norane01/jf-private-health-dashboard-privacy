Atlas Read-Only Workspace

Private, personal-use Gmail and Google Calendar briefing integration

Atlas Read-Only Workspace helps one authorized user create private daily briefs from their own Gmail inbox and Google Calendar.

Limited read-only access

The integration requests only these Google OAuth permissions:

  • Read Gmail messages and threads
  • Read Google Calendar events

It cannot send, change, or delete email. It cannot create, change, or delete calendar events.

Private operation

The integration runs in the authorized user's private Hermes Agent environment. Its purpose is limited to collecting relevant inbox and calendar information, producing personal summaries and reminders, and maintaining the minimum local state needed for those briefs.

Privacy
